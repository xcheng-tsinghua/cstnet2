# ABC mf30 数据集抽样诊断

## 范围与方法

- 数据集：https://huggingface.co/datasets/ZXCCHENGXI/cstnet2_s1_abc_mf30
- 检查时版本：`b1413702e2091b5b6c86228672843ed274b62c82`。
- 数据集 manifest：135,523 个样本、68 个分片。
- 检查分片：0、13、26、33、46、59、67；每个分片检查全部样本和点。
- 共 13,523 个样本（约 9.98%）、27,695,104 个点，其中 loc 有效点 25,774,700 个。
- 这是覆盖前中后位置的分片抽样，不是独立均匀随机抽样，不能保证捕获全数据集的最极端样本。
- 本次没有训练模型或读取训练 checkpoint；所有“零预测”统计均为假设 loc 全部输出零的诊断，不是训练模型的实际误差。
- 未修改训练、推理、损失函数或原始数据。拟合实验仅离线诊断。

## 结论

抽样中没有发现普遍的 XYZ / 几何标签尺度错配。确实存在非常长尾的 loc 标签，主要来自圆锥锥顶；圆柱也有少量远处轴线。直接使用 loc MSE 会对这类目标非常敏感。

但是这批样本的零预测 loc 平均距离误差为 0.495228，不是 4–5。因此，仅凭这次抽样还不能证明训练曲线上的 4–5 全由目标长尾造成。还需用相同 checkpoint 在本批样本上评估，区分未抽到的极端样本、模型输出偏差与训练/评估口径差异。

## 坐标与标签一致性

XYZ 各轴范围：

- X：[-1.004877, 1.002551]
- Y：[-1.003434, 1.024494]
- Z：[-1.009789, 1.009290]

坐标约在 [-1,1]，少量点略微超界，不能断言严格都在此区间。检查的字段中未发现 NaN / Inf。

将 GT 参数代回解析曲面，计算对应点的几何残差：平面为法向距离，圆柱为到轴线距离减半径的绝对值，球面为到球心距离减半径的绝对值。圆锥因轴向符号统一，使用双侧圆锥残差 `abs(radial*cos(angle) - abs(axial)*sin(angle))`。

| 类型 | 平均曲面残差 | P99 曲面残差 | loc 模长均值 | loc 模长 P99 | loc 模长最大值 |
|---|---:|---:|---:|---:|---:|
| 平面 | 4.33e-8 | 6.98e-7 | 0.3913 | 1.0000 | 1.4505 |
| 圆柱 | 3.21e-5 | 5.01e-5 | 0.2724 | 1.3293 | 499.2288 |
| 圆锥 | 4.10e-5 | 1.10e-4 | 5.7085 | 52.3994 | 4779.9150 |
| 球面 | 5.95e-5 | 8.42e-5 | 0.4108 | 3.0655 | 20.0063 |

平面 loc 与法向平行、圆柱 loc 与轴向正交，两项规范检查的最大误差均约 1.1e-6。支持大多数标签已处于正确的规范表示。

存在少量局部异常：6 / 13,523 个点云中至少有一个有效点的 GT 曲面残差大于 0.01，最大圆柱残差约 0.25075。异常样本路径见 `summary.json` 的 `top_residual_instances`；不能仅凭残差区分错误点归属、网格近似或标签问题。

平面和 other 的原始 dim 使用 -1 哨兵。当前加载器会转为零，且损失按 GT 类型排除这些无效维度，因此这不是本次发现的 loc 问题来源。

## 长尾对 MSE 的影响

以下均为同一批有效点上，假设预测 loc = (0,0,0) 的统计：

- 平均欧氏距离：0.495228。
- 中位欧氏距离：0.214545。
- 每坐标平均 MSE（与当前 loc loss 的维度归约一致）：26.502056。
- 圆锥占所有点约 2.40%，贡献位置平方误差的 95.92%。
- loc 模长 > 100：3,899 点，占有效点 0.01513%，贡献位置平方误差的 97.58%。
- loc 模长 > 1000：187 点，占有效点 0.000726%，贡献位置平方误差的 56.04%。

这些是目标分布对平方损失的敏感性证据，不是已训练模型的损失贡献或梯度贡献实测值。

当前 baseline 的 `functional/stage1_direct_loss.py::_masked_mse` 和三阶段方法的 `functional/stage1_phase_loss.py` 都使用有效点 loc MSE。

## 实际远锥顶例子

最大 loc 出现在分片 26、样本索引 44、affiliate_idx=21：

```text
root_000_abc_pcd_mf30/abc_0014_step_v00/
73e3a93d-a789-4c70-83ac-4a813e84c953_00146669_7fc8776177b9f457f6256a98_step_000.txt
```

- 实例只有 30 个点。
- loc = (-4779.915039, 0, 0.076016)。
- 圆锥半角 = 0.000016 rad，约 0.000917°。
- 实例 X 坐标仅覆盖 [0.959671, 0.979650]；Y、Z 均约在 [-0.076, 0.076]。
- GT 曲面平均残差约 0.000623。

这是一小段近似圆柱的极小半角圆锥。点云包围盒不约束其锥顶必须位于同一范围内。

## 离线拟合诊断

在分片 33、样本 1282、affiliate_idx=24 上，甚至提供真实实例分组、真实轴向和轴线，仅对径向距离与轴向坐标做最小二乘直线拟合，再由截距与斜率求锥顶：

| 项目 | 值 |
|---|---:|
| GT 锥顶轴向坐标 | 1717.320557 |
| GT 半角 | 0.00297938° |
| GT 曲面平均残差 | 0.00015465 |
| 拟合锥顶轴向坐标 | 1495.662554 |
| 拟合锥顶误差 | 221.658003 |
| 拟合曲面平均残差 | 0.00002498 |
| 同轴圆柱的平均残差 | 0.00002587 |

这个实验不是完整拟合算法基准，也不是不可恢复性的数学证明，但直接说明本实例中“曲面更贴合”与“锥顶更接近 GT”并不等价。近似圆柱也能以非常小的残差解释局部点云。因此不宜把加权最小二乘视为所有大 loc 误差的必然解法。

## 裁剪指标的解释

按项目新指标的定义，每个点云内部独立裁剪有效点，零预测诊断得到：

| 指标 | loc 平均距离 |
|---|---:|
| 原始 | 0.495228 |
| trim1p | 0.483212 |
| trim5p | 0.434328 |
| trim10p | 0.383836 |

一个极端基元可能在自己的点云内占很大比例，因此即使全数据集只有极少数极端点，每个点云裁剪 1% 也不一定将其剔除。这组数字不是模型训练后的 trim 指标。

## 建议的下一步

1. 用同一训练 checkpoint 对本次抽样数据评估，输出每种基元的预测 loc 模长、误差中位数/P95、原始与裁剪均值、最差样本路径。
2. 在相同样本和口径下比较模型与零预测 0.495228。若模型仍约 4–5，检查模型输出是否普遍偏大、是否被极端样本影响；若抽样上正常，则定位全数据集中的最差样本。
3. 若确认极端参数影响常规样本，可单独做 loc MSE → SmoothL1 的对照实验，保持结构和其他损失不变；此报告未实施损失修改。
4. 几何拟合作为独立对照：分别检查一般基元和近退化圆锥，同时报告参数误差与曲面残差。
