# Semantic 邻域搜索与数值检查优化

本次仅处理三个项目，不修改属性头、cluster 损失、损失权重或冻结策略。

1. 注意力用有序 topk 取最近邻，删除完整 argsort。
2. Attn3DGCN 主流程的输入 PCA 特征、GCN 和注意力共享一次 XYZ 距离计算及 topk。
   邻居数量取三个使用方所需数量的最大值；注意力取前 k 个，GCN/PCA 按原有规则丢弃最近的第一个，再取 k 个。
   共享对象仅存储本次前向的 [B,N,K] 索引和距离，完整 [B,N,N] 距离矩阵用完释放，没有跨 batch 缓存。
   训练、评估、离线生成及冻结提取器使用同一路径。PointNet/PointNet2 不接收 Attn3DGCN 的共享邻域。
3. 模型输出与损失分别进行一次批量有限值标志回传。删除 constraint_loss 内重复检查，保留训练器/评估器在反向之前的检查；异常仍报告具体字段。

网络参数和 checkpoint 格式不变，可以从原 last.pth 继续训练。
重复点、等距离点和浮点近似并列邻居的选择/顺序可能与旧排序不同，不能保证位级复现。
普通非并列输入的旧/新输出和参数梯度已在 CPU、CUDA 上验证，另覆盖重复点、小点集和 NaN/Inf 错误报告。

51 项相关测试通过，包含训练/续训、直接约束、评估、导出、独立 baseline 及之前的 geometry 优化测试。

本机 MX330，batch=2、1024 点、eval 模式下执行梯度计算，预热后 5 次计时中位数：
输入特征 + 模型前向 + semantic 损失 + 反向，原实现 0.1781 秒，优化后 0.1721 秒，约减少 3.4%。
该测试未包含数据读取、优化器更新和有限值检查，且不是用户的 4090/batch=30/2048 点配置；实际整轮提速需在训练机器测量，不能承诺大幅加速。
